About This Project

Sleep Quality and Sleep Disorder Prediction Using XGBoost and Probability Calibration

Purpose of the Project

SleepCare AI is an MSc Data Science project that explores whether everyday lifestyle and health measurements — such as sleep duration, physical activity, stress level and heart rate — can be used to estimate sleep quality and flag the likely presence of a sleep disorder. The application demonstrates an end-to-end machine learning workflow: data preprocessing, model training, probability calibration, and deployment through a web interface.

XGBoost Machine Learning Model

Both prediction tasks are powered by XGBoost (Extreme Gradient Boosting), a tree-based ensemble algorithm well suited to structured/tabular health data. XGBoost builds a sequence of decision trees, where each new tree corrects the errors of the previous ones, producing strong predictive performance on datasets like this one.

Sleep Quality Prediction

The Sleep Quality model is a binary classifier that estimates whether a person's overall sleep quality is likely to be Good or Poor, based on lifestyle and health inputs. It outputs a probability that is translated into a clear label and confidence percentage.

Sleep Disorder Prediction

The Sleep Disorder model is a multi-class classifier trained to distinguish between three categories: No Sleep Disorder, Insomnia, and Sleep Apnea. It produces a probability for each class, and the class with the highest probability is shown as the predicted outcome, alongside the full probability breakdown.

Probability Calibration

Raw probabilities from gradient boosted models are not always well calibrated — a predicted "80% confidence" does not necessarily mean the model is correct 80% of the time. This project applies probability calibration (e.g. Platt scaling / isotonic regression) on top of the base XGBoost outputs so the reported percentages better reflect true likelihoods.

Why Calibrated Probabilities Are Useful

Calibrated probabilities make model outputs more trustworthy and interpretable. Instead of a raw, potentially overconfident score, a calibrated probability gives a more honest estimate of uncertainty — which matters in any health-adjacent context, even an educational one, where over- or under-confident predictions could be misleading.

Educational / Research Purpose Only

SleepCare AI is built strictly for academic demonstration as part of an MSc Data Science project. It does not replace professional medical advice, diagnosis, or treatment. Predictions are model-estimated probabilities based on limited inputs, not clinical assessments. Anyone experiencing persistent sleep problems or symptoms should consult a qualified healthcare professional.
